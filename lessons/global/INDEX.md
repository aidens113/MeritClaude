# Global lessons

Standing preferences and corrections that apply to every repository. One line per lesson; read
the lesson file only when its line is relevant. Maintained by `/lesson`.

- [Act on your recommendation instead of asking](act-on-recommendation-dont-ask.md): When the supervisor already has a recommended option for a decision, Aiden wants it acted on and reported, not put to him as a question, in every project.
- [Answer a direct question in the first line](answer-direct-questions-first.md): When Aiden asks a direct question mid-task, the first line of the reply is the direct answer (a number, an ETA, yes or no), before any status, plan or tool work, in every project.
- [Ask before stopping a paid run at wrap-up](ask-before-stopping-paid-run-at-wrap-up.md): When Aiden asks to wrap up while an approved paid run is in flight, say it is running and ask whether to wait for it or stop it, instead of killing it at once; in every project.
- [Design agent tooling globally, with global and project memory tiers](design-agent-tooling-globally-with-memory-tiers.md): Aiden wants agent instructions, delegation rules, and memory designed to work globally across all his projects, with explicit global shared memory and project-specific memory, and with token cost as a first-class design constraint.
- [Do not stop to report. Announce the next step and take it.](dont-stop-a-report-is-not-an-endpoint.md): Aiden wants the supervisor agent to keep executing until the work is done; ending a turn to report status, or to wait on a background job, counts as stopping and he reacts angrily to it.
- [Enforce standards mechanically on FluxIQ, and do not propose deferral](enforce-standards-mechanically-dont-defer.md): Aiden rejects deferring known structural problems or security weaknesses and wants engineering standards enforced by checks that fail the build rather than by written guidance.
- [Let running agents reach their natural endpoint at wrap-up](let-running-agents-reach-natural-endpoint.md): When Aiden asks to wrap up while subagents or leads are working, let each reach its natural endpoint and integrate it, never interrupt them; record any still running at handoff so the next session can resume them; in every project.
- [Never present an agent's rule as the user's](never-present-agent-rules-as-the-users.md): An agent-derived constraint must never be recorded or cited as the user's rule; before a constraint costs Aiden time or blocks work, confirm he actually stated it, in every project.
- [Never let paid work run without an agent watching it](never-run-paid-work-unsupervised.md): Aiden forbids automation that spends real money (model API calls, paid services) without a live agent supervising it; paid work runs only for a reason and stops at the first balance error, in every project. He does not want a hard budget, only no unattended waste.
- [Parallelize partitionable work instead of queuing it behind one lead](parallelize-partitionable-work-dont-serialize.md): When work is queued behind one long-running agent, Aiden wants every piece that touches none of its files dispatched in parallel immediately, in every project.
- [Report status in plain English](plain-language-status-updates.md): Aiden wants status and progress reports in plain English (what happened, what it means, what's next), with internal codes, run ids and hashes only when he asks for detail, in every project.
- [Recurring failures call for a structural fix, not more patches](recurring-failures-need-structural-fix.md): When the same kind of failure keeps coming back in new shapes, Aiden wants the agent to stop patching each instance and propose and build the structural fix, in every project.
- [A failure report states the cause and the distance travelled](report-failures-with-cause-and-distance.md): Aiden rejects a failure reported as a bare verdict; every failure report must say why it failed and how far it actually got, in every project.
- [Say what you are about to do, then report as it happens](report-progress-and-announce-before-acting.md): Aiden wants to be told what the agent is about to do before it does it, and given detailed updates every time there is progress or a problem, in every project.
- [Schedule estimates are cut for parallel lanes, never padded](schedule-estimates-not-padded.md): Aiden wants plan schedules cut for parallel agent lanes with each date's real constraint named, never padded serial estimates, in every project.
- [Scope required reading by agent role, not by blanket mandate](scope-required-reading-by-agent-role.md): Agent instruction files must scope required reading by who initiated the request, rather than mandating full-document reads for every agent and subagent.
- [Put standing user rules where every agent reads them](standing-rules-where-every-agent-reads-them.md): A standing user rule must be written where every agent reads it (the project's AGENTS.md or CLAUDE.md and each worker brief), and enforced mechanically where possible, never only in the supervisor's local auto-memory.
- [Working documents are the agent memory substrate on FluxIQ](working-docs-as-agent-memory.md): The user wants working documents under docs/working/ used as the durable memory and coordination substrate for agents and subagents.
